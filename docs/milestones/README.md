# Development milestones

These are historical design and implementation records. Their status labels,
test counts, and checklists describe work at the time they were written.

Use the [feature stages](../feature-stages.md), [current roadmap](../state-and-roadmap.md),
and checked-in code/tests for current behavior. Use `td` for active implementation
and review state.
