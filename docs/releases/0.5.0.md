# Futuruna 0.5.0

## Declared rule result types (Experimental)

A rule family now says its type once, on its first line
([RFC](../rfcs/named-scalar-types-and-rule-result-types.md#part-2-declared-rule-result-types)):

```runa
| days_in_month(year: Int, month: Int): Int -> 31
| days_in_month(year, month) -> 30 under month == 4 || month == 6 || month == 9 || month == 11

| fib(n: Int): Int
| fib(0) -> 0
| fib(1) -> 1
| fib(n) -> fib(n - 1) + fib(n - 2)

| ask_danish_dividend_tax_expected_ore(): Ore -> 0
```

- `: R` after a rule head declares the family's result type. The bodiless
  line `| fib(n: Int): Int` declares a family whose first clause matches a
  pattern.
- Types are written on the declaring line only. A type on a later clause or
  an exception, a later clause that calls a parameter by another name, a
  second declaration and a declaration without a clause are errors that name
  the declaring line. A name repeated in one head (`| pairing(a, a)`) is a
  pattern, so it is not a renamed parameter.
- An exception in an importing module writes names only and takes the
  imported declaring line's parameter types.
- `@ cite` above a bodiless declaration is an error: the declaration has no
  clause to cite.
- Each clause is checked against `R`: a number takes `R`'s unit (`-> 0`, not
  `-> Ore(0)`), `None`, `[]` and a shared constructor take their type from
  `R`, and a clause of another type is an error at that clause.
- A family declared `: Bool` answers `False` when no clause applies; a family
  of any other declared type stops with `no value rule matched`.
- Proofs, generated Rust and explanations read the same rules as before: the
  parser writes the declaring line's types onto the later clauses.
- `runa fmt --migrate` writes each family's types once and declares the result
  type where that changes nothing, and lists the families it could not
  declare or rewrite, with the reason.

### Compatibility

A later clause that repeats its family's parameter types no longer parses.
Run `runa fmt --migrate` on the sources.
