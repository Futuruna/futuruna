# Futuruna 0.2.1 release validation

[Futuruna 0.2.1](https://github.com/Futuruna/futuruna/releases/tag/v0.2.1)
was published on 2026-09-27 with four native binaries and `SHA256SUMS`.

The signed `v0.2.1` tag targets
`4db25c97fd16030e5262c4e84ba7d3b841f669e1`, with tree
`8e30ea524ad8f02e643ff325e205588761378082`. Its tree exactly matches the
validated candidate `cbd5bec7d0fb72cb3a6d1c0b1dc19fc2db199947` and the CI
merge ref. The tag's SSH signature was verified against the maintainer's
existing signing key. Tax-model source matches main `550db137` exactly.

## Required gates

[Full CI](https://github.com/Futuruna/futuruna/actions/runs/36321433254)
passed all ten jobs on the validated candidate. Both Linux and macOS completed
`./scripts/mint.sh`, runtime/setup safeguards and the Rust translation corpus.
Differential, canary, downstream, website, editor, formatting, hygiene and
compatibility checks also passed. The complete hosted logs contain no failed
Rust tests; their seven ignored tests per platform remain explicitly ignored.

The documented release gates in [CONTRIBUTING](../../CONTRIBUTING.md) and the
[release runbook](../releasing.md) passed in hosted CI, with all 66 setup commands
and both Rust translation suites also passing locally, plus the four-platform
release rehearsal. No required command or assertion was disabled.

[Release rehearsal](https://github.com/Futuruna/futuruna/actions/runs/36321490498)
passed package verification and all four native builds on the final candidate.
All downloaded architectures and source/package contents passed audit. All four
rehearsal binary hashes exactly match the artifacts exercised in local native,
WebAssembly and translation checks.

The [tagged release workflow](https://github.com/Futuruna/futuruna/actions/runs/36331738736)
passed all seven jobs. Each platform executed its staged binary, weather example,
first-run canary, and runtime compatibility probe. Both actual macOS
signing-status artifacts report `false`: the binaries are unsigned and
unnotarized. crates.io publication was skipped because its registry token was
not configured.

All four public downloads passed `shasum -a 256 -c SHA256SUMS` and ELF/Mach-O
architecture inspection. Their hashes equal the rehearsed binaries. The public
Apple Silicon binary reports `runa 0.2.1` and passed the version/weather/first-run
and runtime checks, all seven interpreted/native fixtures, `runa from-rust --verify examples/from-rust/t18_parser.rs`, the 14 selected calculation CLI tests,
all four input-diagnostic tests, and four serial/parallel assertion/bounds
isolation probes. Valid cases retain their results and order beside failures.

The tagged source package contains exactly 113 intended files (2,500,859 bytes),
with clean VCS metadata identifying `4db25c97`. All Rust sources match that
commit byte for byte; no unexpected paths or missing sources were found.

## Focused local checks

- `cargo fmt --all -- --check`, `python3 scripts/repository-hygiene.py` and
  `git diff --check origin/main...HEAD` passed; hygiene checked 1,605 files.
- `cargo test --locked --lib calculation_execution_tests`: 23 passed.
- `cargo test --locked --test calculate_cli -- calculation_readiness calculation_hydration_reports_every_field_error calculation_runtime_failures_are_case_scoped call_assert_with_message calculation_json_rejects_duplicate calculation_xlsx_duplicate xlsx_strings`:
  14 passed. The new integration regressions preserve every field diagnostic
  without overwriting input/output files, and preserve original case ordering
  and valid results beside draft/runtime failures in serial/parallel JSON/XLSX.
- `cargo test --locked --test from_rust_verify_cli`: 16 passed, including
  value-position `if let` and branch-local binding regressions.
- The CLI unit harness compiles; six focused tests passed for contextual
  optional heads, rejected unsafe misses, structural equality/hash-collision
  witnesses, optional equality and consuming field receivers.
- `cargo test --locked --test calculation_input_diagnostics --test length_operands`:
  all four input-diagnostic and five length-operand tests passed against the
  downloaded compiler. Diagnostic fixtures explicitly mark their authored
  inputs ready; all expected errors and results are unchanged.
- `cargo publish --locked --dry-run` passed from the clean final candidate;
  the upload was aborted by the dry-run flag.
- `cargo build --locked --release --bin runa` passed. Downloaded Apple Silicon
  version/weather/first-run/runtime checks, seven interpreted/native fixtures,
  and four serial/parallel draft/runtime isolation probes passed.
- `FUTURUNA_WASM_CANARY_REQUIRED=1 RUNA_BIN=<downloaded-binary> ./scripts/wasm-canary.sh`:
  both required fixtures passed.
- `runa from-rust --test examples/from-rust/`: 35 exact output matches;
  `RUNA_BIN=<downloaded-binary> ./scripts/from-rust-differential.sh`: all 24
  generated cases matched across six source-shape families.
- All 66 exact post-Mint setup commands from the
  [tagged CI workflow](https://github.com/Futuruna/futuruna/blob/v0.2.1/.github/workflows/ci.yml)
  passed locally after ordinary
  canonical-schema warmup, in 3 hours 15 minutes. The runner began at
  `968325d2`; the only subsequent candidate change was the unrelated Rust
  input-diagnostic fixture file. Production source, setup inputs and the
  optimized compiler binary were unchanged throughout the run. The optional
  saved-output viewer probe was skipped because no external fictional fixture
  was supplied.
