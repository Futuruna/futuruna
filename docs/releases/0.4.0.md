# Futuruna 0.4.0

## Unit types (Experimental)

- **Declaration.** `# unit Ore "DKK øre"` declares a unit of measure for
  whole numbers. The description says what the unit counts. `unit` is
  contextual and stays an ordinary name elsewhere; it has no Danish keyword.
  Units exist for `Int` only.
- **Arithmetic.** `Ore + Ore`, `Ore - Ore`, `Ore % Ore` and `-Ore` are `Ore`;
  `Ore * n`, `n * Ore`, `Ore / n` and `Ore % n` are `Ore`; `Ore / Ore` is a
  plain `Int`. `Ore * Ore`, `n / Ore`, mixing two units, and adding or
  comparing `Ore` with a named plain `Int` are type errors whose messages name
  the fix.
- **Literals.** A number written in the source takes the unit its place
  requires: `amount > 0`, `amount + 100`, an `Ore` field given `0`, a match
  arm `| None -> 0` beside an `Ore` arm and `= amounts: List(Ore) = [0, 100]`
  need no conversion.
- **Callbacks.** The parameter of a `map`, `filter`, `foldl` or other
  collection callback has the element type, so a wrong unit inside the
  callback is caught, and `sum_list(map(xs, |x| x.amount))` keeps the unit.
- **Conversions.** `Ore(n)` gives a plain `Int` the unit and `Int(amount)`
  takes it off; a change of unit is a function that uses both. `abs`,
  `min_int`, `max_int`, `clamp`, `sum` and `sum_list` keep the unit.
- **Runtime unchanged.** The interpreter, `runa call` JSON, `runa verify` and
  generated Rust see plain `Int`; generated Rust declares `pub type Ore = i64;`.
- **Contract.** `runa schema` adds `"unit": "Ore"` to primitive `Int` type
  references with a unit and a top-level
  `"units": [{"name": "Ore", "description": "DKK øre"}]`. Field metadata of a
  unit-typed field takes its `unit` text from the declaration; an authored
  `unit = Some(...)` on such a field is an error.
- **Folds and rule families.** `foldl` with a literal start takes the unit
  when its step adds a value of exactly one unit
  (`foldl(items, 0, |total, item| total + item.amount)` is `Ore`); write
  `Ore(0)` only when the step adds no unit value. A rule family may mix literal
  clauses (`-> 0`) with unit clauses and has the unit; such a family, a
  RuleScope member and a function over a unit are generated as Rust over `i64`.
