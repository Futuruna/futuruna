# Futuruna 0.4.0

## Constructor names scoped to their type (Experimental)

- **Shared constructor names.** Two sum types in one scope may declare the
  same constructor name, such as `Trade` in `Event` and in `AskYearEvent`. A
  use takes its owner from the type the context expects: a pattern from the
  matched value, an argument, field or result from its declared type, one side
  of `==` from the other side.
- **`Type.Constructor`.** An expression or a pattern can name the owner
  explicitly: `AskYearEvent.Trade(...)`, `| AskYearEvent.Closed -> ...`.
- **No guessing.** A shared name with nothing to give it a type is an error
  that names the owners and the explicit spellings; the owner is never chosen
  by arity or by field names.
- **Data keeps the declared names.** `$variant` in calculation JSON, contracts,
  `runa schema`, displayed values and solver models use the name the
  declaration wrote, and so do generated Rust enums (`AskYearEvent::Trade`).
  The WebAssembly engine runs such models as `runa call` does. Programs
  without shared names are unchanged.

See [the RFC](../rfcs/scoped-constructors.md).
