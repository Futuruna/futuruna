# Futuruna 0.4.0

## TypeScript SDK reads as TypeScript (Experimental)

`runa sdk ts` generates TypeScript that a TypeScript team would write by hand,
while the engine keeps its JSON: the SDK encodes each case before a call and
decodes the result and the needs after it. See
[Calculations](../reference/calculations.md#typescript-sdk).

- **camelCase fields.** `opening_cash_ore` is `openingCashOre` in the types,
  the validators, the partial cases, `setAt` and the resolver patterns; it
  stays `opening_cash_ore` on the wire. Two fields of one record or variant
  with the same camelCase name are an error.
- **Enums are strings.** A sum type whose variants carry no fields is a string
  union: `direction: "Deposit"` instead of `{ $variant: "Deposit" }`. A sum
  type with payload variants stays a union tagged by `$variant`, a name no
  field can take.
- **Dates are ISO strings.** A `Date` is `"2026-03-01"` (`IsoDate`), validated
  as a day on the calendar, and `{ year, month, day }` on the wire.
- **Needs at TypeScript paths.** `need.path`, `unusedPaths` and an entry
  need's `subject` are the paths a TypeScript caller writes:
  `events[0].amountOre`, an enum at its own path (`events[0].direction`) and a
  date as a whole (`events[0].date`, one need for the date's parts). The
  partial types write an unknown variant as `Unknown<T>`.
- **One shared runtime.** `setAt`, `resolve`, the paths, the needs, the calls,
  the wire codec and the error classes are generated once into a runtime
  module that every entry imports; `--runtime ../runtime.ts` lets the SDKs of
  several source files share one copy. Each entry generates only its types,
  validators, codecs, path tables and functions.
- **Wire codecs.** `schema.ts` has a codec per record and union, and
  `<entry>Entry` names an entry's input and result codecs; `toWire`,
  `fromWire` and `fromWirePath` convert `runa call` documents and paths; a
  field a codec does not know throws `WireError`, so a result that arrives with
  TypeScript names instead of the engine's is an `output` error.

### Compatibility

- Code written against the 0.3 SDK changes with it: field names are camelCase,
  enum values are strings, dates are ISO strings, need paths are TypeScript
  paths, and `unused_paths`, `waiting_rule`, `attachment_path` and a
  diagnostic's `case_id` are `unusedPaths`, `waitingRule`, `attachmentPath`
  and `caseId`. Partial unions use `Unknown<T>` for `{}`, and an enum or a
  date has no `Partial` type of its own.
- `runa sdk ts` writes `runtime.ts` next to the entry modules unless
  `--runtime` names another place. A contract type named like a runtime
  export (`Unknown`, `IsoDate`, `Codec`, …) or `<Type>Codec` must be renamed.
- `runa call`, `runa call --partial` and the contracts are unchanged.
