# 0.2.0 integration validation

Status: **released on 2026-09-19**. [Futuruna 0.2.0](https://github.com/Futuruna/futuruna/releases/tag/v0.2.0)
contains all four native binaries and `SHA256SUMS`. Delivery is tracked in
`td-54f105`; stabilization and shared-import parity are submitted for independent
review in `td-e9e823` and `td-066cc7`. General cross-parent ownership remains
separately tracked in `td-625bb9`.

### Stabilization contract

- Shared plain/hash ADT imports retain constructor declaration provenance;
  direct qualified aliases and different source files remain distinct. Equality
  and collection hashing agree even for keys constructed before the root import.
  Root values and existing Explore value encodings are unchanged.
- Bare mixed-arity constructor names fail closed as exact values, including
  contextually annotated uses. Arithmetic backend typing does not certify
  potentially overflowing operations as total.
- Fully enumerated plural questions can publish classification summaries from
  their exact extensional seals without inventing a symbolic-support closure.
  Case-support graph v5 versions this changed authority contract; old v4 output
  directories must not be reused. No saved checkpoint/result bundle was changed.
- Symbolic collections remain deferred during elaboration. Permanent executable
  stream tests now assert rejection of malformed members and open RuleScopes
  at consumption; reversed/oversized ranges and import-prefix capture retain
  their separate ground-evaluation guards. Stream binding-plan preparation also
  rejects imported bindings that capture later root declarations, with a
  dedicated executable preparation regression. Nested failure causes are preserved.
- Remaining fixture corrections cover current syntax, canonical AST paths,
  platform-specific telemetry, dependency-valid cursor insertion, exact arity,
  declaration-environment memo guards, and isolated nested constructors.

Local iteration uses `CARGO_BUILD_JOBS=1 CARGO_PROFILE_DEV_DEBUG=0
CARGO_PROFILE_TEST_DEBUG=0 CARGO_INCREMENTAL=0 cargo test --locked` with focused
library/bin filters, followed by the built library harness's named regression
selection (`--test-threads 1`). It does not substitute for full mint or deeper CI.

The new `tests/differential/corpus/imports/shared_import_enum.runa` passes
