20% millicore reserve (1,200 on six cores; 3,200 on sixteen), preserving worker
ceilings. The standalone module test suite passes all 31 tests.

root/plain/qualified shared-import codegen. They do not broaden exact proof
authority or implement general cross-parent ownership. With a single-job local

  element types and an authored function shadowing the intrinsic.

  comparing interpreter and generated Rust.

  roundtrip passed (outputs `2` and `8`).
