# 0.2.0 release validation

Status: **released on 2026-09-19**. [Futuruna 0.2.0](https://github.com/Futuruna/futuruna/releases/tag/v0.2.0)
contains all four native binaries and `SHA256SUMS`. General cross-parent
ownership remains separately tracked in `td-625bb9`.

## Final sign-off and published artifacts

[Final integration CI](https://github.com/Futuruna/futuruna/actions/runs/35442577436)
passed all eight jobs on `9ab85ae4f518dbe37dd8a1a9aa10421b0d5e74f7`:
full Linux/macOS mint, canary, differential, downstream consumers, formatting,
compatibility, and website SSG. No required gate was waived.

- Linux: 770 library and 451 CLI unit tests passed; seven library tests remain
  explicitly ignored.
- macOS: 776 library and 455 CLI unit tests passed; seven library tests remain
  explicitly ignored. All six supervised Explore CLI scenarios passed together.
- Both platforms: all 52 calculation and five verification CLI tests passed;
  the interpreted/native corpus passed 119 positive and 29 expected-error cases;
  all 35 from-Rust examples matched and all 354 corpus files were formatted.
- Existing optional-dependency/runner skips are not counted as passes. For
  example, macOS expectations passed 87 cases with eight skips, and roundtrip
  matched 81 cases with 38 skips. Separate import-aware and canary lanes passed.

The [exact-candidate release dry run](https://github.com/Futuruna/futuruna/actions/runs/35442606761)
passed packaging and all four native builds, weather examples, and first-run
checks. Its package contained 100 paths, bound the exact candidate in VCS
metadata, and excluded private/generated/research/test trees.

[PR 1](https://github.com/Futuruna/futuruna/pull/1) was merged only after those
gates passed. Merge commit `91bef04d057f94e0531918f2691b3e7acefd0038` has tree
`89dbe2a0e56c73823aef07b7e24a16da90d4e7b3`, exactly equal to the tested candidate.
The signed `v0.2.0` tag binds that merge commit; its SSH signature was verified
locally against the existing maintainer key. This is not a claim about GitHub's
account-level signature badge or Apple Developer ID signing.

[Tag release workflow](https://github.com/Futuruna/futuruna/actions/runs/35447144230)
passed all jobs and published the GitHub release at 14:03:30 UTC. Downloaded
assets were verified with `shasum -a 256 -c SHA256SUMS` after the download
completed: all four passed. `file` confirmed ELF x86-64/AArch64 and Mach-O
arm64/x86-64. The downloaded Apple Silicon binary passed `runa --version`
(`runa 0.2.0`), `runa examples/weather_demo.runa`, and
`RUNA_BIN=<downloaded-binary> ./scripts/first-run-canary.sh` locally. Every
platform's native smoke checks also passed in the tag workflow.

macOS assets are not Apple-signed or notarized. The workflow explicitly skipped
crates.io publication because `CARGO_REGISTRY_TOKEN` was absent; a successful
optional publishing job does not mean a crate was published. Browser-quarantine
Gatekeeper behavior and a clean-agent website installation were not rechecked
locally; the native first-run checks do not claim those separate validations.

The automatically triggered main CI run was cancelled as duplicate work after
confirming the merge tree exactly matched the all-green candidate. Cancellation
is not passing evidence; the final integration and tag workflows above are the
release evidence.
