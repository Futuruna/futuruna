# Futuruna 0.2.4

Futuruna 0.2.4 fixes six cases in which a program the interpreter runs failed
to compile to native code, and adds `json_has`.

## Language

- **Tuple types.** `(Int, String)` is a type wherever a type is written, so a
  function can declare a tuple result: `> pair(x: Int) -> (Int, String)`.
  Followed by `->`, the parentheses still list the parameters of a function
  type. Rules and functions that return tuples compile to Rust tuples.
- **Omitted result types.** A top-level function that omits `-> Type` gets the
  result inferred from its body, in compiled code as in the interpreter. When
  the body ends in a value whose type cannot be inferred, native compilation
  reports a located error that asks for a declared result type.
- **`json_has(object, key)`** is `true` when the JSON object has the member,
  including a member whose value is `null`, and `false` for a missing member or
  JSON that is not an object. `json_get` returns `null` in both cases. The
  Danish name is `json_har`.
- **`abs`** keeps the numeric type of its argument, `Int` or `Float`, in both
  execution modes.

## Native compilation

- **Rule results from builtins.** A rule whose result comes from a builtin is
  typed from the builtin's arguments: `abs`, `nth`, `fst`, `snd`, `trd`, `sum`
  over `Float`, `random_choice` and `shuffle`, and the builtins with one fixed result such as `index_of`,
  `max_f`, `join`, `split`, `starts_with` and `http_respond`. Such rules were
  skipped with "cannot infer every return clause".
- **`http_serve` handlers that read top-level bindings.** A handler, written
  as a closure or named as a function, may read top-level bindings directly or
  through the functions it calls. The server shares one copy of them, taken
  when `http_serve` starts, between all requests.
- **Boolean rules called from closures.** A Boolean rule called inside a
  closure with a local binding as its argument compiles: a callback parameter
  of `map`, `filter`, `any`, `all`, `find` and the other collection builtins
  has the element type of the collection, and a binding's declared type is the
  type of the binding.

## Documentation

- The HTTP server is built on `axum` and `tokio`, not `tiny_http`.
- `runa build FILE` writes the binary, named after the source file, to the
  directory the command runs in.
- `json_get` returns `null` for a missing member.

## Installation

Use the checksummed binaries on the
[GitHub release](https://github.com/Futuruna/futuruna/releases/tag/v0.2.4), or
build the tag with
`cargo install --git https://github.com/Futuruna/futuruna --tag v0.2.4 --locked futuruna`.
