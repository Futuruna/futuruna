# Futuruna 0.9.0 (unreleased)

## Explore

- **A successor can call a polymorphic helper.** A helper whose signature
  uses a type variable, such as `> others(all: List(a), current: a) ->
  List(a)`, can be called from the helpers of an Explore transition:
  `transition after in neighbours(before)` with `neighbours` returning
  `map(others(all_kinds, row.kind), |kind| Row(kind = kind, n = row.n))`
  explores to an exact closure. Each call is typed by binding the type
  variables from its arguments, so `others(all_kinds, row.kind)` has the type
  `List(Kind)` there. Before, `runa explore` refused the query with
  `checked exploration boundary is unavailable:
  Producer(SemanticDependencyClosureUnsealed { layer: "relation", ... })`. A
  call whose result type its arguments do not fix (such as a call of
  `> nothing(n: Int) -> List(a)`) is still refused.
