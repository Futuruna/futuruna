# Futuruna 0.9.0 (unreleased)

## Native code

- **Callers read a rule family over constructor patterns natively.** A rule
  that calls a family whose clause heads match every variant
  (`| level(First) -> Supreme`, `| level(Second) -> High`, …) compiles
  natively also when the caller's name sorts before the family's. Such a
  caller compared or returned the family's result without unwrapping it, and
  the generated Rust did not compile (`expected Option<Court>, found Court`).
