# Futuruna 0.2.0

This release integrates the bounded-Explore, income-distance, and static
rule-dispatch work previously developed on separate branches.

## Highlights

- Experimental finite-space exploration with named questions, one-unit edges
  across multiple dimensions, deterministic mechanism evidence, and exact
  regional proofs that can close large ranges at once.
- Resumable authenticated journals and incremental result artifacts, with
  explicit opt-in trust for pinned, previously checked recovery evidence.
- Resource-governed execution, macOS containment and telemetry recovery, and
  bounded native acceleration for supported query shapes.
- Rule-dispatch soundness and qualified-namespace verification fixes, with
  permanent interpreter/native/solver parity coverage.
- A completed, documented income-cliff exploration over the encoded 2026
  model: annual income 0–400,000 DKK and commuting distance 0–200 km, with
  one-krone and one-kilometre transitions. See the
  [workbook](../../examples/danish-income-tax/exploration-workbook.md) for exact
  domain, exclusions, findings, and assumptions.

## Upgrade Notes

Explore remains Experimental; this release does not promise arbitrary checkpoint
or artifact compatibility across revisions. Preserve old evidence together with
its compiler and source identity. Trusted recovery does not independently reprove
that evidence, and restoration can still involve journal replay.

See the [0.2.x compatibility guide](../compatibility-guides/0.2.x.md) for the
bug-fix exceptions and supported boundaries. Legal and tax models remain research
software, not individual advice.

## Distribution

The release workflow produces Linux x86-64/ARM64 and macOS Intel/Apple Silicon
binaries with `SHA256SUMS`. The published GitHub release records the actual
macOS signing/notarization status. crates.io publication is optional and depends
on the configured registry credentials; native assets do not imply a new crate
was published.
