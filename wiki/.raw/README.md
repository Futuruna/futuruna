# Raw Source Staging

This hidden folder is the staging area for raw materials that should feed the Futuruna vault without being rewritten in place.

Use it for:

- exported issue threads
- pasted design notes
- PDFs and paper drafts
- web clips or copied upstream bug reports
- benchmark data and audit exports

- treat files here as immutable inputs
