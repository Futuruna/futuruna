# Repo Map

## Main Folders

- `src/`: Rust compiler, runtime, proof, and codegen implementation
- `docs/`: language docs, milestones, references, and roadmap material
- `tests/`: Futuruna language programs, regression fixtures, and canaries
- `research/`: exploratory design and analysis
- `paper/`: paper drafts and publication artifacts
- `wiki/`: Obsidian knowledge layer
- `.raw/`: hidden staging area for raw imported sources
