# Rust

Rust is a strong Futuruna comparison point for compiler professionalism because it combines a stability story, a very large structured test harness, and real ecosystem regression testing.

## Relevant To Futuruna

- release trains and "stability without stagnation"
- compiletest and many specialized suites
- broad ecosystem regression testing beyond the core repo
- strong pressure against breakage on stable users
