# Kotlin

Kotlin is a useful Futuruna comparison point because it documents language evolution as a managed compatibility discipline rather than an informal promise.

## Relevant To Futuruna

- named pre-stable feature statuses
- explicit compatibility categories
- published compatibility guides per release
- willingness to treat some compiler bug fixes as justified incompatibilities
