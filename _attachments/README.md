# Attachment Staging

Use this folder for images, PDFs, exports, and other media that should be embedded from wiki notes.

Rules:

- keep large or user-specific binaries curated
- prefer linking from `wiki/` notes rather than dropping files in the repo root
- if a file is a raw source rather than a reusable reference asset, put it in `.raw/` instead
